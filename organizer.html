Installation

  1. Download and open the DMG file.
  2. Drag LPF Organizer into the Applications folder.
  3. Open LPF Organizer from Applications.
If macOS blocks the first launch

LPF Organizer is independently distributed and is not notarized by Apple. macOS may ask you to approve it the first time.

  1. Try opening LPF Organizer normally.
  2. If macOS blocks it, open System Settings → Privacy & Security.
  3. Find the message about LPF Organizer and select Open Anyway, then confirm.

Only approve the app if you downloaded it from the official LPF website or its GitHub release. You should not need to repeat this for normal launches.
