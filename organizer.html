Organize — Copy or move related RAW, JPEG and XMP files into date-based folders. Preview the plan with Dry Run and undo supported file operations.

Cull — Compare photographs, mark Keep, Maybe or Reject, and assign star ratings. When you're ready, a separate, confirmed command moves rejected photo groups to the macOS Trash, with a limited Undo option.

Metadata — Preview photographs in the workspace while editing titles, descriptions, keywords, location and ratings in XMP sidecars. Apply changes to one photo or a selection.

Location & XMP — Describe places with Sublocation, City, Region, Country and Country Code. Exchange these fields with DxO PhotoLab 9 while preserving existing GPS and Location Created metadata.

Explorer handoff — Open selected photographs from LPF Explorer directly in Organizer for metadata work.

Installation

  1. Download the latest ZIP file from GitHub Releases.
  2. Double-click the ZIP file to extract the application.
  3. Move LPF Organizer.app to the Applications folder.
  4. Open LPF Organizer from Applications.

LPF Organizer is signed with an Apple Developer ID certificate and notarized by Apple. On first launch, macOS may show its normal confirmation that the app was downloaded from the internet. You can open it normally; no security workaround is required.
