LPF Organizer

Version 1.0.1 · Available now

Organize, cull and describe your photographs. Work directly with your files and folders, with no cloud, catalogue or subscription.

Organize — Copy or move photos into date-based folders, with Dry Run and Undo.

Cull — Review photos, mark Keep, Maybe or Reject, and assign star ratings.

Metadata — Edit titles, descriptions, keywords, location and ratings using XMP sidecars.

Explorer handoff — Open selected photographs from LPF Explorer directly in Organizer for metadata work.

Installation

  1. Download LPFOrganizer-1.0.1.zip from GitHub Releases.
  2. Double-click the ZIP file to extract the application.
  3. Move LPF Organizer.app to the Applications folder.
  4. Open LPF Organizer from Applications.

LPF Organizer is signed with an Apple Developer ID certificate and notarized by Apple. On first launch, macOS may show its normal confirmation that the app was downloaded from the internet. You can open it normally; no security workaround is required.
