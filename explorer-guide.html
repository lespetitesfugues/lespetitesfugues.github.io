1. What LPF Explorer is for

LPF Explorer helps you find, browse, select and reuse photographs in an existing folder-based archive. It is the companion to LPF Organizer, which handles organizing, culling and descriptive metadata editing. Explorer is intentionally a lightweight retrieval tool rather than a second photo editor or a catalogue that owns your photographs.

A typical workflow is: import and organize photographs with LPF Organizer; add useful XMP metadata; keep the photographs in ordinary folders; later use LPF Explorer to find them by content, date, rating or Finder tag; assemble a selection; then open the photographs in your preferred editor or return to Organizer when metadata needs correcting.

2. The archive belongs to you

Explorer works with the folders and files already on your disk or NAS. There is no import into a proprietary library, no cloud account and no requirement to move photographs into Explorer's own storage. The archive is the source of truth. Explorer maintains a disposable local index for speed, not a replacement for your files or a backup.

The intended main archive layout is a folder such as PhotoStore, with year folders and date folders below them (for example PhotoStore/2024/2024-04-27). Explorer does not require this naming convention to browse photographs. Temporary working copies on a notebook SSD can be kept outside the main archive.

First start: choose the archive with Choose Archive… (Command–O). Explorer scans its contents and builds the local index. Later launches can reuse cached metadata and synchronize changes. If you change the archive root, the displayed folder hierarchy and archive-associated collections follow that archive.

3. The three ways to find photographs

The sidebar offers three complementary approaches. They serve different purposes, so you need not use all of them.

  • Archive folders: Browse by where photographs live. Selecting a folder includes photographs in its subfolders. Choose Entire Archive to work across the complete archive.
  • Smart collections: Save a question you want to ask repeatedly: for example, photographs from a trip, rated at least four stars, or marked with a particular Finder tag. The result changes as metadata and files change.
  • Manual collections: Save a selection of particular photographs, even when those photographs come from different years or folders. Membership is chosen by you rather than by search rules.

The distinction is important: a folder is a filesystem location, a smart collection is a saved search, and a manual collection is a saved set of photo references. Creating either kind of collection does not move or duplicate the underlying photographs.

4. Browsing the archive

Expand the Archive section in the sidebar to navigate the folder tree. Select a year or date folder to see photographs recursively beneath it. A folder without children does not need an expansion triangle. The grid displays the matching photographs; adjust thumbnail size to balance overview and detail. Explorer remembers your grid zoom setting.

Select Entire Archive when you want to search beyond the currently selected folder. The selected scope is indicated in the sidebar. A search can also be restricted to a folder, including all its subfolders, and that scope can be saved as part of a smart collection.

5. Searching and filtering

Use the free-text search field for words appearing in filenames, titles, descriptions, keywords and location metadata. Multiple search terms narrow the result. Good descriptive metadata written earlier in Organizer makes these searches much more useful.

Filters can be combined:

  • Rating: Set a minimum star rating (for example, four stars or higher). This is a threshold, not an exact rating.
  • Finder tag: Restrict results to one tag, or to untagged photographs. Finder tags can express a workflow state such as working, finished, used or needing attention; they are not substitutes for descriptive XMP keywords.
  • Capture date: Choose any date, a fixed year, the current year, or a date range. Ranges can use fixed boundaries or a relative boundary such as Today. A saved relative date remains relative when you open the collection later.
  • Sort: Filename A–Z or Z–A, capture date newest or oldest, and rating highest or lowest. Manual collections also offer their own collection order.

The filters act together. For example, a search for landscape with a minimum rating of four stars and a specific year returns only photographs satisfying all three conditions. Clearing filters returns to an unfiltered view of the current scope.

6. Smart collections: searches you can return to

Smart collections are useful for recurring questions, not just one-time searches. First select the archive or folder scope, enter text and filters, and save the current criteria as a smart collection. Give it a meaningful name such as Tour de Romandie 2017 or Finished landscapes.

When you select a smart collection, its saved search text, rating, Finder tag and capture-date criteria appear in the toolbar. Its saved scope appears in the compact row beneath the filters. These controls show what the collection means, rather than leaving you to guess from its name.

Editing a smart collection: Changing a filter or the scope while that smart collection is selected updates the saved definition. This is intentional. If you want a different search without changing the saved collection, first select a regular archive folder or Entire Archive. The Clear Filters command also clears the selected smart collection's saved filters when a smart collection is active.

Smart collections do not store copies of photographs. If new photographs satisfy the criteria after synchronization, they appear in the results; if metadata changes so a photograph no longer matches, it disappears from that smart collection.

7. Manual collections: selections you curate

Use a manual collection when the choice of photographs matters more than a repeatable search rule: a shortlist for an exhibition, a set for a family album, or images gathered for a presentation. Create a manual collection, select photographs in the grid and add them through the available collection action or drag-and-drop.

A photograph may belong to multiple manual collections. Manual collections reference the photographs in the archive; they do not create new files. When appropriate, choose Collection order to use the manual ordering rather than sorting by date, filename or rating.

For example, you might create Portfolio candidates, add images found in several smart searches, and then use that manual collection to review the final selection.

8. Keeping many collections organized

Groups are optional and deliberately limited to one level. Manual Collections and Smart Collections each have their own groups; a group cannot contain the other type of collection. Ungrouped collections remain directly visible under their section.

Use the folder-plus control in the appropriate sidebar section to create a group. Move collections into or out of groups by dragging them or using Move to Group in the context menu. Groups can be renamed, expanded and collapsed. Group membership and expanded state persist between launches.

Deleting a group does not delete its collections: they return to the ungrouped level. Groups are purely for navigation; they do not affect the collection's search criteria, membership or photographs. For example, groups named By Year, Trips and Projects can make a long smart-collection list easier to navigate.

9. Selecting, inspecting and opening photographs

The thumbnail grid is designed for fast keyboard navigation. Use the arrow keys, Page Up/Down and Home/End to move through results. Hold Shift while navigating to extend a selection, use Command–A to select all displayed photographs, and Space to open Quick Look.

The optional right-hand information panel displays read-only metadata, including description, capture information and file details. It helps answer what is this photograph? without turning Explorer into another metadata editor. With multiple photographs selected, the panel emphasizes the selection count rather than trying to merge their metadata.

Use the context menu to reveal files in Finder, open them with an application, or send photographs to LPF Organizer for descriptive metadata editing. RAW and JPEG variants can be associated as a photograph pair; the files remain available to external editors.

10. Explorer and Organizer: complementary roles

LPF Organizer is for preparing the archive: organizing files, culling, assigning ratings and writing descriptive XMP metadata such as title, description, keywords and location. LPF Explorer is for retrieving and using the result of that work. Explorer keeps descriptive metadata read-only, avoiding two competing editors for the same fields.

Consider a practical sequence:

  • After a trip, organize the files into the archive with Organizer, cull the rejects and describe the useful photographs.
  • Weeks or years later, search Explorer for the place, date or subject, then narrow by rating or Finder tag.
  • Save that query as a smart collection if it will be useful again; make a manual collection if you need to curate a particular set of images.
  • Open selected photographs in an external editor, or choose Edit Metadata in LPF Organizer when descriptions or keywords need improvement.

The benefit comes from ordinary files plus portable metadata. Your photographs remain accessible in Finder and other applications even if you stop using either LPF application.

11. Synchronization, caches and unavailable files

Explorer indexes file metadata to make searching responsive. It monitors filesystem changes and supports Synchronize Archive (Command–R). After a metadata edit or external file operation, synchronization updates the index so searches reflect the archive.

The local index and thumbnail caches are disposable performance aids, not authoritative databases. They should not be treated as a backup. If the archive is temporarily offline, cached metadata may still be visible, but opening an unavailable original file requires reconnecting the archive. Reconnect and synchronize when the storage becomes available again.

If a file has been renamed, moved or deleted outside Explorer, an existing collection reference may no longer resolve to the original photograph. Keep the archive structure reasonably stable and use synchronization after major reorganizations. Collections are not a substitute for filesystem backups.

12. A few practical examples

Find the best photographs from a particular trip

Select Entire Archive, enter the trip name or location in the search field, limit the capture dates to the trip, and set a minimum rating. Save the result as a smart collection if you expect to revisit it.

Maintain a changing set of finished photographs

Filter by the Finder tag you use for finished work, optionally require a minimum rating, and save as a smart collection. As you update tags or ratings in your normal workflow, the saved search reflects the new state after synchronization.

Assemble photographs for a presentation

Search across folders and years, select suitable photographs and add them to a manual collection. Repeat with other searches. The manual collection is the curated selection; it need not correspond to any single search or folder.

Keep dozens of saved searches navigable

Create smart-collection groups such as Trips, People, By Year or By Rating. Move existing collections into groups without changing their saved definitions. Collapse groups you are not currently using.

14. Design principles and support

LPF Explorer is deliberately small, focused and efficient. It does not require a cloud service, a proprietary catalogue, an account or a subscription. Its goal is to help you find and use photographs without taking ownership of your archive. New features are considered only when they support that goal without unnecessary overhead.

LPF Explorer is free to use. If you find it useful, the About and Support windows contain an optional Ko-fi link. Donations are appreciated but never required, and no donation reminder interrupts normal work.
