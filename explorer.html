LPF Explorer

Version 1.0.0 · Available now

Find and explore your photographs without importing them into a catalogue. Browse existing folders, search XMP metadata and build collections — all locally.

Browse — Explore folders and subfolders in your existing photo archive.

Search — Find photographs using filenames, XMP titles, descriptions, keywords and locations.

Filter — Narrow results by rating, date, Finder workflow tags and RAW/JPEG availability.

Collections — Create manual collections and smart collections for recurring searches.

Organizer handoff — Open selected photographs in LPF Organizer V1.0.1 or later for metadata editing.

Installation

  1. Download LPFExplorer-1.0.0.zip from GitHub Releases.
  2. Double-click the ZIP file to extract the application.
  3. Move LPF Explorer.app to the Applications folder.
  4. Open LPF Explorer from Applications.

LPF Explorer works independently. LPF Organizer V1.0.1 or later is needed only for the handoff feature.

LPF Explorer is signed with an Apple Developer ID certificate and notarized by Apple. On first launch, macOS may show its normal confirmation that the app was downloaded from the internet. You can open it normally; no security workaround is required.
