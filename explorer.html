Browse your archives — Switch between photo archives, folders and collections, including archives on external drives. Your folders remain ordinary folders.

Metadata Search — Search filenames, XMP titles, descriptions, keywords and locations; narrow results by rating, date, Finder tags and EXIF information.

Visual Search — Describe what a photograph looks like. The optional SigLIP 2 model analyses images and search descriptions locally on your Mac.

Automatic indexing — Visual indexes update incrementally as photographs are added or changed, while you continue browsing.

Collections — Curate photographs in manual collections or save recurring metadata searches as smart collections, without copying originals.

Organizer handoff — Open selected photographs in LPF Organizer when descriptive metadata needs editing.

Installation

  1. Download the latest ZIP file from GitHub Releases.
  2. Double-click the ZIP to extract the application.
  3. Move LPF Explorer.app to Applications.
  4. Open LPF Explorer and add an existing photo archive. Metadata Search works immediately.

Visual Search is optional. If you choose to use it, Explorer asks permission before downloading the approximately 750 MB SigLIP 2 model from Hugging Face. Allow at least 2 GB of free space. Install it once per Mac, not once per archive. You may also install compatible model files from a local folder.

Image analysis and Visual Search run on your Mac. Your photographs and visual-search descriptions are never uploaded to an AI service. Only the optional model download and a lightweight software update check use the network.

LPF Explorer works independently. LPF Organizer is needed only for the handoff feature.

LPF Explorer is signed with an Apple Developer ID certificate and notarized by Apple. macOS may display its normal downloaded-app confirmation on first launch; no security workaround is needed.
