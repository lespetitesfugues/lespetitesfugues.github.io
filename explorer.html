LPF Explorer

Version 1.0.0 · Available now

Find and explore your photographs without importing them into a catalogue. Browse existing folders, search XMP metadata and build collections — all locally.

Download LPF Explorer 1.0.0

Free · macOS 14 Sonoma or later

Release notes and SHA-256 checksum on GitHub →

Browse — Explore folders and subfolders in your existing photo archive.

Search — Find photographs using filenames, XMP titles, descriptions, keywords and locations.

Filter — Narrow results by rating, date, Finder workflow tags and RAW/JPEG availability.

Collections — Create manual collections and smart collections for recurring searches.

Organizer handoff — Open selected photographs in LPF Organizer V1.0.1 or later for metadata editing.

Installation

  1. Download and open the DMG file.
  2. Drag LPF Explorer into the Applications folder.
  3. Open LPF Explorer from Applications.

LPF Explorer works independently. LPF Organizer V1.0.1 or later is needed only for the handoff feature.

If macOS blocks the first launch

LPF Explorer is independently distributed and is not yet notarized by Apple. macOS may ask you to approve it the first time.

  1. Try opening LPF Explorer normally.
  2. If macOS blocks it, open System Settings → Privacy & Security.
  3. Find the message about LPF Explorer and select Open Anyway, then confirm.

Only approve the app if you downloaded it from the official LPF website or GitHub release. Do not bypass a malware or damaged-app warning.
